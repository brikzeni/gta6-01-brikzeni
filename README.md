SUNDOWN DISTRICT — an original open-world crime game set in Cinder Bay, built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

You are Rae, a former courier. One wrong delivery pulls you into a criminal network run by property developers and private security. Explore a living coastal city on foot and by car, steal vehicles, outrun the CBPD wanted system, fight, and complete a three-mission story arc: The Wrong Delivery, Evidence Run, and Sundown Escape.

The game includes a procedural four-district city (Harborfront, Sunline Blvd, Old Market, Crown Heights) with traffic, pedestrians, police pursuit, combat, a minimap HUD, save/load, procedural WebAudio, and a title screen over a live 3D city. Everything — city, cars, people, story, art, sound — is original, built with vendored three.js, and runs offline from static files with no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

Controls: WASD move / drive, mouse look (click to lock), Shift sprint, Space jump / handbrake, F enter or exit a car, E interact, click fire, R reload, M missions, P pause and save.
